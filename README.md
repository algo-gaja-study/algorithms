# 알고리즘 스터디

## 스터디 규칙

- **기간**: 2026년 10월 01일 (목) ~ 2026년 12월 31일 (목)
- **문제 풀이**: 매일 1문제씩 (평일만, 주말 제외 / 난이도 무관)
- **제출 마감**: 당일 23:59까지
- **벌금**: 김지호(통장)에게 입금, 추후 회식비로 사용
  - 미제출: 5,000원

평일로 습관 잡힌 후 주말로 확장 예정

## 파일명 규칙

- **날짜 기준**: `YYMMDD` 형식 (ex. `251229.cpp`, `260101.cpp`)
- 본인 이름 폴더 내에 주차별로 정리

## 커밋 규칙

```
[사이트] 문제번호 문제이름 (난이도)
```

예시:

- `[PGS] 12345 타겟 넘버 (Lv.2)`
- `[BOJ] 2557 Hello World (B5)`
- `[SWEA] 1234 문제이름 (D3)`
- `[LEET] 1234 문제이름 (Medium)`

## 자동 회비 시스템 (GitHub Actions)

- 워크플로우 `Fees`가 **매일 자정(00:00 KST)**에 실행되어 전날(평일) 제출 여부를 확인합니다.
- **제출 기준**: 마감(23:59 KST)까지 `main`에 `{GitHub 아이디}/**/YYMMDD.*` 파일이 있으면 제출로 봅니다.
- 미제출자는 아래 **회식비 누적 금액**에 **5,000원**이 자동으로 더해지고, `회비` 라벨 Issue로 기록이 남습니다.
- 같은 날짜는 한 번만 부과됩니다. Actions 탭에서 날짜를 지정해 수동 실행(`dry_run` 지원)할 수 있습니다.
- 참여자를 추가할 때는 `참여자` 표와 `회식비 제공 천사` 표에 모두 행을 추가해 주세요.
